# Agents, Tools, and Skills

**Agents:** Ingestion, Retrieval, Context/Reranking, Grounding/Citation, Evaluation.

**Skills:** ingestion planning, retrieval assessment, context selection, grounding verification, answer evaluation.

**Tools:** ingestion record, retrieval record, reranking/context record, grounding record, evaluation record.

Retrieval quality and answer quality are evaluated separately. Missing citations or insufficient grounding remains explicit.
